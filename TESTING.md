# Чеклист для тестирования фронтенда

## Подготовка к тестированию

1. **Убедитесь, что бэкенд запущен**
   - Бэкенд должен быть доступен по адресу `http://localhost:3380`
   - Или измените `PUBLIC_API_URL` в `.env` файле

2. **Создайте файл `.env`** (если его нет):
   ```env
   PUBLIC_API_URL=http://localhost:3380/api
   ```

3. **Установите зависимости** (если еще не установлены):
   ```bash
   npm install
   ```

4. **Запустите dev сервер**:
   ```bash
   npm run dev
   ```

5. **Откройте браузер**: `http://localhost:5173`

## Известные проблемы и ограничения

1. **Tailwind CSS**: Убедитесь, что Tailwind настроен правильно. Если стили не применяются:
   - Проверьте наличие `tailwind.config.js`
   - Проверьте наличие `postcss.config.js`
   - Убедитесь, что Tailwind установлен: `npm install -D tailwindcss postcss autoprefixer`

2. **API URL**: По умолчанию используется `http://localhost:3380/api`. Если бэкенд на другом адресе, создайте `.env` файл.

3. **CORS**: Убедитесь, что бэкенд разрешает запросы с фронтенда.

## Рекомендации по тестированию

1. **Начните с базовой функциональности**: главная страница, каталог, просмотр товара
2. **Протестируйте авторизацию**: регистрация, вход, выход
3. **Протестируйте корзину**: добавление, изменение, удаление
4. **Протестируйте оформление заказа**: полный цикл от корзины до создания заказа
5. **Проверьте обработку ошибок**: неверные данные, сетевые ошибки
6. **Проверьте адаптивность**: на разных размерах экрана
