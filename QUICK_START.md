# Быстрый старт для тестирования

## 1. Подготовка

```bash
# Установите зависимости (если еще не установлены)
npm install

# Установите @tailwindcss/postcss для Tailwind CSS v4
npm install -D @tailwindcss/postcss

# Создайте файл .env (если его нет)
echo "PUBLIC_API_URL=http://localhost:3380/api" > .env
```

## 2. Запуск

```bash
# Запустите dev сервер
npm run dev
```

Сервер запустится на `http://localhost:5173`

## 3. Проверка базовой функциональности

### Минимальный тест (без бэкенда):
1. Откройте `http://localhost:5173`
2. Проверьте, что страница загружается
3. Проверьте, что Header и Footer отображаются
4. Перейдите в каталог - должна быть ошибка загрузки данных (это нормально, если бэкенд не запущен)

### Полный тест (с бэкендом):
1. Убедитесь, что бэкенд запущен на `http://localhost:3380`
2. Откройте `http://localhost:5173`
3. Проверьте основные страницы:
   - Главная (`/`)
   - Каталог (`/catalog`)
   - Поиск (`/search?q=test`)
4. Попробуйте зарегистрироваться или войти
5. Добавьте товар в корзину
6. Перейдите в корзину
7. Попробуйте оформить заказ (требует авторизации)

## 4. Проверка консоли браузера

Откройте DevTools (F12) и проверьте:
- Нет критических ошибок JavaScript
- Нет ошибок загрузки ресурсов
- API запросы отправляются корректно

## 5. Известные проблемы

Если стили не применяются:
- Убедитесь, что установлен `@tailwindcss/postcss`: `npm install -D @tailwindcss/postcss`
- Проверьте наличие `tailwind.config.js` и `postcss.config.js`
- Перезапустите dev сервер

Если возникает ошибка о PostCSS плагине:
- Установите `@tailwindcss/postcss`: `npm install -D @tailwindcss/postcss`
- См. подробности в `TAILWIND_FIX.md`

Если API запросы не работают:
- Проверьте, что бэкенд запущен
- Проверьте `PUBLIC_API_URL` в `.env`
- Проверьте CORS настройки бэкенда
