# API: Корзина

Базовый префикс: **`/api`**.

Идентификация для корзины — **один из двух вариантов** (обязательно один):

1. **Авторизованный пользователь:** заголовок `Authorization: Bearer <access_token>` (JWT). Корзина привязана к пользователю.
2. **Гость:** заголовок **`X-Session-Id`** (произвольная строка, например UUID с фронта). Корзина привязана к этой сессии.

Без JWT и без `X-Session-Id` запросы к корзине вернут **401**.

---

## Эндпоинты

Базовый путь: **`/api/cart`**.

### Получить корзину

**`GET /api/cart`**

Возвращает текущую корзину (по `userId` из JWT или по `X-Session-Id`). Если корзины ещё нет — создаётся пустая.

**Ответ:** объект корзины с полями `id`, `userId`, `sessionId`, `createAt`, `updateAt`, `items` — массив позиций. Каждая позиция: `id`, `cartId`, `productId`, `quantity`, `product` (объект товара).

---

### Добавить товар в корзину

**`POST /api/cart/items`**

**Тело (JSON):**

| Поле       | Тип    | Описание |
|------------|--------|----------|
| `productId` | number | Id товара. |
| `quantity`   | number | Количество (минимум 1). |

Если товар уже есть в корзине — количество складывается с текущим, но не превышает остаток по товару (`product.quantity`). Если товара нет в наличии или не найден — ошибка.

**Ответ:** обновлённая корзина (как в GET /api/cart).

---

### Изменить количество позиции

**`PATCH /api/cart/items/:id`**

**Тело (JSON):**

| Поле       | Тип    | Описание |
|------------|--------|----------|
| `quantity` | number | Новое количество (≥ 0). Если 0 — позиция удаляется из корзины. |

Количество ограничивается остатком товара на складе.

**Ответ:** обновлённая корзина.

---

### Удалить позицию из корзины

**`DELETE /api/cart/items/:id`**

`id` — id позиции в корзине (CartItem), не productId.

**Ответ:** обновлённая корзина.

---

### Очистить корзину

**`DELETE /api/cart`**

Удаляются все позиции из текущей корзины.

**Ответ:** корзина с пустым массивом `items`.

---

### Слияние гостевой корзины после логина

**`POST /api/cart/merge-session`** — требуется **JWT** (только для авторизованных).

После входа пользователя можно перенести гостевую корзину (собранную по `X-Session-Id`) в корзину пользователя.

**Тело (JSON):**

| Поле        | Тип   | Описание |
|-------------|-------|----------|
| `sessionId` | string | Тот же значение, что использовалось в заголовке `X-Session-Id` до логина. |

**Логика:** корзина с данным `sessionId` ищется; все её позиции добавляются в корзину пользователя (количество не превышает остаток по товару, дубликаты по товару объединяются). Гостовая корзина после слияния удаляется.

**Ответ:** корзина пользователя с объединёнными позициями.

**Пример сценария:** гость с `X-Session-Id: abc-123` добавляет товары в корзину. После логина клиент отправляет `POST /api/cart/merge-session` с заголовком `Authorization: Bearer <token>` и телом `{ "sessionId": "abc-123" }`. В ответе — корзина пользователя с товарами из гостевой корзины.

---

## Ошибки

- **400** — товар не найден, нет в наличии, некорректное количество и т.п.
- **401** — нет ни JWT, ни заголовка `X-Session-Id`, или невалидный токен.
- **404** — корзина или позиция корзины не найдена (например, чужая корзина).
