# API: Адреса доставки

Базовый префикс: **`/api`**.

Все эндпоинты требуют **JWT** (заголовок `Authorization: Bearer <access_token>`). Работа только с адресами текущего пользователя.

Базовый путь: **`/api/addresses`**.

---

## Эндпоинты

### Список адресов

**`GET /api/addresses`**

Возвращает все адреса текущего пользователя. Адрес по умолчанию (`isDefault: true`) первым в списке.

**Ответ:** массив объектов с полями `id`, `userId`, `label`, `city`, `street`, `building`, `apartment`, `postalCode`, `phone`, `isDefault`, `createAt`, `updateAt`.

---

### Один адрес по id

**`GET /api/addresses/:id`**

**Ответ:** объект адреса. 404 — если адрес не найден, 403 — если адрес принадлежит другому пользователю.

---

### Добавить адрес

**`POST /api/addresses`**

**Тело (JSON):**

| Поле        | Тип     | Обязательное | Описание |
|-------------|---------|--------------|----------|
| `label`     | string  | да           | Подпись (например «Дом», «Офис»), до 100 символов. |
| `city`      | string  | да           | Город, до 255 символов. |
| `street`    | string  | да           | Улица, до 255 символов. |
| `building`  | string  | да           | Дом/корпус, до 50 символов. |
| `apartment` | string  | нет          | Квартира/офис, до 50 символов. |
| `postalCode`| string  | нет          | Индекс, до 20 символов. |
| `phone`     | string  | да           | Телефон, до 50 символов. |
| `isDefault` | boolean | нет          | Сделать адресом по умолчанию (по умолчанию false). Если true — у остальных адресов пользователя isDefault сбрасывается. |

**Ответ:** созданный объект адреса.

---

### Редактировать адрес

**`PATCH /api/addresses/:id`**

Все поля опциональны (частичное обновление). Формат полей — как в создании. Если передан `isDefault: true`, у остальных адресов пользователя isDefault сбрасывается.

**Ответ:** обновлённый объект адреса.

---

### Сделать адрес по умолчанию

**`PATCH /api/addresses/:id/default`**

Делает указанный адрес адресом по умолчанию для заказов (у остальных адресов пользователя isDefault сбрасывается).

**Ответ:** обновлённый объект адреса.

---

### Удалить адрес

**`DELETE /api/addresses/:id`**

**Ответ:** `200` и `{ "message": "Адрес удалён" }`. 404/403 — как в GET по id.

---

## Коды ответов

- **200** — успешный запрос.
- **201** — адрес создан (POST).
- **400** — невалидные данные (валидация DTO).
- **401** — нет или невалидный JWT.
- **403** — попытка доступа к чужому адресу.
- **404** — адрес не найден.

---

## Миграции

Таблица адресов создаётся миграцией:

